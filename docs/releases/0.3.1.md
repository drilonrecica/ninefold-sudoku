# Ninefold Sudoku 0.3.1

Release date: 2026-07-25

Release: `0.3.1` portable single-resource Compose deployment

`0.3.1` does not change gameplay, HTTP, WebSocket, persistence, or replay schemas. It replaces the
two-application operational model with one provider-neutral Compose resource containing an
isolated Caddy gateway, SvelteKit web service, and single-replica Go server.

## Deployment changes

- only `gateway:8080` is exposed to Coolify; web and server have no host ports or domains;
- the gateway routes public API/WebSocket traffic, compresses responses, caches immutable assets,
  removes forged admin/proxy headers, and returns 404 for private routes;
- `compose.standalone.yaml` publishes 80/443 and persists Caddy certificate state for ordinary
  Docker hosts;
- all services use read-only roots, tmpfs scratch space, health checks, resource limits, and
  non-root users;
- only the server mounts `ninefold-data`, has a 60-second stop grace period, and is fixed at one
  replica.

## Trust and privacy changes

`cmd/deployment-config` creates a mode-`0600` non-overwriting production environment file containing
independent cookie, Ed25519 replay-signing, and internal proxy secrets. It emits the matching raw
replay public key and stable key ID without printing secret values.

The production web image requires the generated key ID and public key at build time. The matching
private key is loaded only by the server, so the deployed client trusts replays produced by its
paired backend. Development/test builds retain the fixed fixture key.

The gateway normalizes client addresses from its configured trusted proxy chain and authenticates
the value to Go. Go compares the proxy secret in constant time and falls back to the socket peer
for missing, malformed, or forged identity headers. IP-based room creation and room-code throttles
therefore remain independent behind Coolify without trusting public forwarding headers.

## Qualification

The release is qualified with:

```sh
make test
make lint
make generate
make puzzles
make build
make e2e
make tla
docker compose --env-file <generated-file> -f compose.yaml config
docker compose --env-file <generated-file> -f compose.yaml -f compose.standalone.yaml config
sha256sum --check release/checksums-0.3.1.txt
```

CI additionally validates both Caddy configurations, builds the paired production images, runs the
Go race detector and dependency audits, and scans the server, web, and pinned Caddy images for high
or critical vulnerabilities.

Release-input checksums are in
[`release/checksums-0.3.1.txt`](../../release/checksums-0.3.1.txt).
