# Ninefold Sudoku 0.3.2

Release date: 2026-07-25

Release: `0.3.2` Coolify gateway packaging fix

`0.3.2` fixes the gateway startup failure discovered during the first Coolify deployment of
`0.3.1`. It does not change gameplay, HTTP, WebSocket, persistence, or replay schemas.

## Fix

The gateway image now contains both the Coolify and standalone Caddy configurations. The base
Compose stack no longer bind-mounts a repository-relative file into `/etc/caddy/Caddyfile`.

Coolify executes Compose against an artifact directory that is not a source path on the target
Docker host. The old bind source was therefore created as a directory, and Caddy failed with:

```text
read /etc/caddy/Caddyfile: is a directory
```

The standalone override selects the embedded HTTPS configuration through the container command and
retains only its certificate and configuration-data volumes.

## Deployment

Use [`deploy/COOLIFY.md`](../../deploy/COOLIFY.md) and deploy immutable annotated tag `v0.3.2`.
Existing generated `0.3.1` environment values remain valid; update only `NINEFOLD_VERSION` to
`0.3.2`.

## Qualification

The release validates both base and standalone Compose configurations, validates both embedded
Caddy files from the built image, runs the full application checks, and scans all three images.

Release-input checksums are in
[`release/checksums-0.3.2.txt`](../../release/checksums-0.3.2.txt).
