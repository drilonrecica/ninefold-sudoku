# Ninefold Sudoku 0.3.3

Release date: 2026-07-26

Release: `0.3.3` temporary closed-beta puzzle seed

`0.3.3` fixes match startup on fresh production databases. It does not change gameplay, HTTP,
WebSocket, or replay schemas.

## Closed-beta catalog

Migration 17 inserts 10 pre-generated, validated, multiplayer-approved beta puzzles:

| Difficulty | Count |
| ---------- | ----: |
| Easy       |     3 |
| Medium     |     3 |
| Hard       |     2 |
| Expert     |     2 |

The catalog supports an initial match and one rematch at every difficulty. Further same-room
rematches may exhaust the available puzzles because recent-puzzle exclusion remains enforced. This
temporary catalog does not satisfy the documented development or public catalog targets.

Seeded puzzle revisions are immutable. The migration ignores an already-present matching primary
key and intentionally does not delete seeded content when rolled back, preserving historical match
and replay references.

## Deployment

Use [`deploy/COOLIFY.md`](../../deploy/COOLIFY.md) and deploy immutable annotated tag `v0.3.3`.
Existing `v0.3.2` secrets and the SQLite volume remain valid; update only `NINEFOLD_VERSION` to
`0.3.3`. Migration 17 runs automatically during server startup.

## Qualification

The release validates all catalog records and their canonical uniqueness, verifies fresh and
version-16 database upgrades, checks exact seeded metadata and difficulty counts, exercises match
and replay behavior, and runs the complete CI and image-scan suite.

Release-input checksums are in
[`release/checksums-0.3.3.txt`](../../release/checksums-0.3.3.txt).
